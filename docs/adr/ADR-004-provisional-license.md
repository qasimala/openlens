# ADR-004: Provisional GPL-2.0-or-later license

- Status: Accepted for development; review required before distribution
- Date: 2026-08-08

Original OpenLens code is authored under GPL-2.0-or-later. Dependencies retain their own licenses and notices. No scrcpy source is copied. The final dependency inventory, OBS toolchain terms, FFmpeg configuration, Android libraries, and packaging require review before distributing binaries.
